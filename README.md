# Шахматы под прикрытием

Нестандартный вариант шахмат с элементами дедукции и скрытой информацией. Игра рассчитана на двух игроков за одним экраном (hot-seat).

## Правила игры

### Доска и расстановка
- Стандартная доска 8×8.
- Каждый игрок свободно расставляет свои 16 фигур на **две свои горизонтали** (белые — 1-я и 2-я, чёрные — 7-я и 8-я).
- Расстановка произвольная: не обязательно следовать классической схеме.
- Фаза расстановки завершается, когда оба игрока разместили все фигуры.

### Ходы и фигуры
- Фигуры ходят по стандартным шахматным правилам (пешка, конь, слон, ладья, ферзь, король).
- Пешка может ходить на 2 клетки вперёд **только со 2-й горизонтали** (своей стартовой).
- Рокировка и взятие на проходе **отсутствуют**.
- Пешка, достигшая последней горизонтали, **превращается** в любую фигуру (выбор появляется автоматически).

### Скрытность и дедукция
- Своя сторона доски видна полностью.
- Фигуры соперника скрыты: отображаются как **нумерованные кружки** (1–16).
- Игрок может самостоятельно отслеживать возможные типы скрытых фигур в панели дедукции.
- При ходе фигуры её возможные типы сужаются на основе **геометрии хода** (какие фигуры способны сделать такой ход).
- Работает **подсчёт по количеству**: если на доске осталось 3 скрытые фигуры, которые могут быть только конями, а у игрока всего 2 коня — одна из них точно не конь.
- При взятии скрытой фигуры её реальный тип отображается в панели.

### Победа
- Победа достигается **физическим взятием короля соперника**.
- Шах и мат не проверяются — игра идёт до захвата короля.

## Стек

- **React 19** — UI-фреймворк
- **Vite 8** — сборщик и dev-сервер
- **TypeScript 6** — типизация
- **CSS Grid** — верстка доски и интерфейса
- Без внешних шахматных библиотек — вся логика написана с нуля

## Структура проекта

```
src/
├── game/
│   ├── moves.ts       # Валидация ходов, фильтрация типов, итеративная дедукция
│   └── board.ts       # Утилиты: координаты, клонирование, перемещение фигур
├── components/
│   ├── App.tsx        # Корневой компонент, переключение экранов
│   ├── GameView.tsx   # Управление состоянием партии, ходы, превращения, дедукция
│   ├── Board.tsx      # Доска 8×8, метки a-h/1-8, нумерация скрытых фигур, клики
│   ├── Piece.tsx      # Отображение фигуры (Unicode-символ или номер)
│   ├── SetupBoard.tsx # Экран расстановки, перетаскивание/клик
│   ├── DeductionPanel.tsx  # Панель дедукции, debug-режим, история ходов
│   └── HandoffScreen.tsx  # Экран передачи хода между игроками
├── types.ts           # TypeScript-интерфейсы (Piece, Board, Move, константы)
└── main.tsx           # Точка входа
```

## Запуск

```bash
npm install          # Установка зависимостей
npm run dev          # Запуск dev-сервера (localhost:5173)
npm run build        # Сборка в production (папка dist/)
npm run preview      # Предпросмотр собранной версии
npm run lint         # Проверка кода (oxlint)
```

## Отладка

- В панели дедукции есть чекбокс **Debug**. При включении:
  - Рядом с каждым номером отображается **реальный тип** фигуры соперника.
  - Если выбранный тип не совпадает с реальным, ячейка подсвечивается красным.
  - Полезно для проверки логики дедукции и тестирования.
- В консоль браузера выводятся логи дедукции: какие типы были удалены, сколько итераций выполнено, достигнута ли стабильность.
