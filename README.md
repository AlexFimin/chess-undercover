# Шахматы под прикрытием

Онлайн-версия нестандартных шахмат с элементами дедукции и скрытой информацией. Два игрока играют по сети: создают комнату и подключаются по 6-значному коду.

## Правила игры

### Доска и расстановка
- Стандартная доска 8×8.
- Каждый игрок свободно расставляет свои 16 фигур на **две свои горизонтали** (белые — 1-я и 2-я, чёрные — 7-я и 8-я).
- Расстановка произвольная: не обязательно следовать классической схеме.
- Фаза расстановки завершается, когда оба игрока разместили все фигуры.

### Ходы и фигуры
- Фигуры ходят по стандартным шахматным правилам (пешка, конь, слон, ладья, ферзь, король).
- Пешка может ходить на 2 клетки вперёд **только со 2-й горизонтали** (своей стартовой).
- Рокировка и взятие на проходе **отсутствуют**.
- Пешка, достигшая последней горизонтали, **превращается** в любую фигуру (выбор появляется автоматически).

### Скрытность и дедукция
- Своя сторона доски видна полностью.
- Фигуры соперника скрыты: отображаются как **нумерованные кружки** (1–16).
- При ходе фигуры её возможные типы сужаются на основе **геометрии хода** (какие фигуры способны сделать такой ход).
- Работает **подсчёт по количеству**: если все фигуры, которые могут быть конями, уже вскрыты/взяты — конь исключается из возможных типов остальных.
- При взятии скрытой фигуры её **реальный тип раскрывается** (взятая фигура отображается в панели дедукции).

### Победа
- Победа достигается **физическим взятием короля соперника**.
- Шах и мат не проверяются — игра идёт до захвата короля.

## Архитектура

Клиент-серверная модель с серверной валидацией:

```
Браузер A (React SPA)  ←─WebSocket─→  Node.js сервер  ←─WebSocket─→  Браузер B (React SPA)
```

### Разделение данных

| Данные | Где хранятся | Кто видит |
|---|---|---|
| Реальные типы фигур | Сервер | Только сервер |
| Позиции, ID, owner, hasMoved | Сервер → оба клиента | Оба |
| pieceNumbers (1-16) | Сервер назначает | Оба |
| possibleTypes (дедукция) | Клиент (локально) | Каждый свой |
| Валидация ходов, победа | Сервер | Только сервер |

Ключевой принцип безопасности: клиент **никогда** не получает `type` для чужих фигур — реальные типы фигур соперника существуют только на сервере. Дедукция вычисляется локально на каждом клиенте из публичной истории ходов.

### Wire-протокол (Socket.IO)

**Клиент → Сервер:** `create_room`, `join_room`, `submit_setup`, `make_move`, `choose_promotion`, `leave_room`

**Сервер → Клиент:** `room_created`, `room_joined`, `waiting_for_opponent`, `opponent_joined`, `game_started`, `move_result`, `promotion_request`, `opponent_left`, `error`

## Стек

- **React 19** — UI-фреймворк
- **Vite 8** — сборщик и dev-сервер
- **TypeScript 6** — типизация
- **Node.js + Socket.IO** — игровой сервер (валидация, комнаты, состояние)
- **CSS Grid** — верстка доски и интерфейса
- Без внешних шахматных библиотек — вся логика написана с нуля

## Структура проекта

```
server/
├── index.ts           # Socket.IO сервер, обработка событий (порт 3001)
├── rooms.ts           # Управление комнатами (создание, подключение, очистка)
└── game.ts            # Игровое состояние, валидация ходов, назначение номеров

src/
├── net/
│   └── socket.ts      # Socket.IO клиент + типы событий
├── game/
│   ├── moves.ts       # Генерация ходов + дедукция (shared с сервером)
│   └── board.ts       # Утилиты доски: координаты, клонирование, перемещение
├── components/
│   ├── App.tsx        # Фазы: menu → waiting → setup → playing
│   ├── Lobby.tsx      # Создание комнаты / подключение по коду
│   ├── Setup.tsx      # Расстановка своих 16 фигур
│   ├── GameView.tsx   # Игровой процесс: shared state (с сервера) + локальная дедукция
│   ├── Board.tsx      # Доска 8×8, метки a-h/1-8, нумерация скрытых фигур
│   └── DeductionPanel.tsx  # Панель дедукции: возможные типы, история ходов фигуры
├── types.ts           # Типы + wire-протокол (shared с сервером)
└── main.tsx           # Точка входа
```

## Запуск для разработки

Два терминала:

```bash
# Терминал 1: игровой сервер (порт 3001)
npm run server

# Терминал 2: Vite dev-сервер (порт 5173, проксирует /socket.io на 3001)
npm run dev
```

Открыть `http://localhost:5173` в **двух браузерах** (например, обычный + инкогнито):
1. В первом: «Создать комнату» → получить 6-значный код
2. Во втором: «Подключиться» → ввести код
3. Оба игрока расставляют фигуры → игра начинается

**Windows-упрощение:** `start-dev.bat` запускает оба процесса в отдельных окнах.

## Продакшен-сборка

```bash
npm run build     # Собирает клиент в dist/
npm start         # Запускает сервер, раздаёт dist/ + WebSocket на одном порту
```
